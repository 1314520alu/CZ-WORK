# CS35 工程说明

整理日期：2026-11-10  
对象：CS35 涡轴发动机，ArduPilot 直升机固件，斜盘为 eRob。  
当前编译目标：零一飞行 X9（`ZeroOneX9`，板号 5601）。  
这份说明记录已经落地的软件和接口，不是试车放行。

## 1. 系统分工

飞控不直接加油，也不直接开关起动机。飞控通过 ARINC 429 把模式、总距和旋翼转速告诉发动机 ECU，加油、点火、起动时序由 ECU 自己完成。斜盘仍由 eRob 打，和发动机是两条线。

链路：

飞控以太网 → 亿佰特 NT1-M → 板内 TTL UART → 展翼 RS422-429-1C → 发动机 ECU。

- 总线 100 kbps。飞控到 ECU 的刷新周期 12.5 ms，ECU 到飞控 24 ms。
- 展翼封装是 `C0` 加 4 字节小端。只把 Label 字节做位反转，不要整字反转。
- `C0` 只存在于转换模块的串口打包里，不会出现在 429 总线上。
- 不要自动发 `CD` 速率命令。
- J202 针 15/16 是 ECU 到飞机，针 17/18 是飞机到 ECU。

CUAV X7 PRO 没有网口，不能走这条 NT1-M 链路。X9 的 hwdef 保留 RMII 网口 `ETH1`，`AP_NETWORKING_ENABLED` 为 1。

## 2. 起动怎么发生

没有单独的“起动”429 字。发动机侧确认：起动机和点火的接通、断开、时序由 ECU 自动做。飞机把 PMS 给到慢车或飞行即可。

429 上的 PMS 是指令字 340、342、344，三份内容相同：

| 编码 | 含义 |
| --- | --- |
| `001` | 停车 |
| `011` | 慢车 |
| `100` | 飞行 |

地面起动发慢车 `011`。ECU 内部会经过“起动”，再进“慢车”。回传字 171 用来看结果：bit 14 点火、bit 15 起动电机、bit 16 起动电磁阀，bit 18–21 的状态机里 2 是起动、3 是慢车、4 是飞行。

起动发电机的大电流不走 429，直接接飞机起动电源和 GCU。ECU 只发控制信号，到慢车后断开起动供电。

冷运转、假起动、通道切换是上升沿指令，不能长期置 1。当前软件把这些位保持为 0，不绑到飞行模式。

## 3. 飞控怎么选模式

遥控器上要有一个两档开关，专门切停车和慢车。旋翼互锁仍用原来的电机互锁辅助功能（选项 32），不要和发动机开关共用。

`A429_ENG_CH` 为 0 时，飞控不改 340/342/344。设成 1 到 16 时，该通道 PWM 大于 1800 为慢车请求，低位、中位、无效遥控器或失控保护为停车。

| 慢车开关 | 已解锁 | 互锁打开 | 发给 ECU |
| --- | --- | --- | --- |
| 关 | 任意 | 任意 | `001` 停车 |
| 开 | 否 | 任意 | `011` 慢车，持续发送 |
| 开 | 是 | 否 | `011` 慢车，持续发送 |
| 开 | 是 | 是 | 立刻 `100` 飞行 |

解锁不决定停车还是慢车。慢车可以在解锁之前就建立。

互锁打开后不能继续守着 `011`。慢车功率带不起旋翼转速。互锁一开并且已经解锁，就要发 `100`，ECU 才按总距和实测 Nr 把转速加上去。总距在带转时保持小桨距。

转速起不来的收回条件默认关闭。只有 `A429_NR_REF`、`A429_NR_CRIT`、`A429_RUNUP` 都不是 0，并且转速计有真实采样时才生效：Nr 百分比等于 `转速 × 100 / A429_NR_REF`。低于临界百分比持续超过 `A429_RUNUP` 秒，锁回 `011`，直到互锁松开或上锁解除。没有转速采样不会因此退回慢车。已经达到临界转速之后的短暂回落，也不会因此退回。

总距字 310 和旋翼转速字 311 仍来自仿真快照，还没有从直升机总距和转速计自动填入。
