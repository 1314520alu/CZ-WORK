## 2. 烧录前要先改的参数

镜像里这些默认值都是 0。只打开 `A429_ENABLE` 不会按遥控器去控发动机。

改完 `A429_ENABLE` 后需要重启，才能看到其余 `A429_` 项。

```
NET_ENABLE    = 1
A429_ENABLE   = 1
A429_IP0..3   = NT1-M 的实际 IP
A429_REM_PORT = NT1-M 的实际 TCP 端口
A429_FRAME    = 2
A429_SDI      = 0
A429_ENG_CH   = 慢车/停车开关所在的遥控器通道号
```

`A429_FRAME=2` 才是展翼 RS422-429-1C。不要用 `FRAME=1`。不要指望飞控发送 `CD` 速率命令。飞控自己的地址仍用原来的 `NET_IPADDR*`、`NET_NETMASK`、`NET_DHCP`。

遥控器：

- 一个空通道接两档开关，高位为慢车，低位为停车。把该通道号填进 `A429_ENG_CH`。
- 互锁继续用辅助功能 32（电机互锁），常见是 `RC6_OPTION = 32`，以实际通道为准。
- `H_RSC_MODE` 用外置调速器。不要用遥控直通，也不要用油门曲线给这台涡轴加油。

转速保护先保持关闭：`A429_NR_REF`、`A429_NR_CRIT`、`A429_RUNUP` 保持 0。三件事确认后再一起填写：100% Nr 对应的转速、临界百分比、允许带转的秒数，以及转速计实例 `A429_NR_INST`（0 表示 RPM1）。

`A429_NG_TO`、`NP_TO`、`T45_TO`、`MKP_TO`、`WN1_TO`、`ST_TO`、`WN2_TO` 先保持 0。

## 3. 地面操作顺序

1. 飞机在地面，互锁关闭。慢车开关先放在停车，确认飞控发出的是 `001`。
2. 慢车开关拨到慢车。飞控持续发 `011`。ECU 自己接通起动机和点火。此时可以还没有解锁。
3. 看 ECU 回传：171 里起动电机和点火是否接通，状态是否进到慢车；同时看 Ng、Np、T45、扭矩和告警。慢车稳定后再往下走。
4. 解锁，打开互锁。飞控立刻改发 `100`，总距保持小桨距。Nr 应在此后上升。
5. 飞行中保持 `100`。定点、自动、返航只改航路，不改发动机模式。
6. 着陆后收总距，关掉互锁或解除解锁，回到 `011`。转速和温度合适后，把慢车开关拨回停车，发出 `001`。

冷运转、假起动、通道切换、超转检查用专用开关或地面站，不要绑到飞行模式。
